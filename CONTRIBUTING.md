# Contributing to Awesome Kamal

We welcome practical Kamal tools, deployment recipes, learning resources, and relevant commercial offerings.

## Suggesting a resource

Use the [suggest resource form](https://github.com/awesome-kamal/awesome-kamal/issues/new/choose) or open a pull request modifying the appropriate file in `resources/`.

Each record needs a stable kebab-case `id`, a concise `name`, a direct HTTPS `url`, a `category` matching the filename, a factual `description`, a `kind` (open-source, documentation or commercial), and `tags`.

Do not edit `catalog.json` or `README.md` directly; run `npm run build` to regenerate them, then `npm run check`. No dependencies are required for these commands.

## Editorial policy

Resources must have substantive Kamal relevance; not every application tagged Kamal qualifies. We flag historical Kamal 1/MRSK patterns and avoid untested compatibility claims. Commercial and competing products are welcome. Sponsorship does not affect listing inclusion or order. We may decline entries that are broken, duplicates, promotional-only, or insufficiently relevant.

The directory is independent and supported by [Upstate](https://upstate.cloud/), a commercial Kamal product.
