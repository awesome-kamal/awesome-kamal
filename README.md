# Awesome Kamal

A community-curated directory of tools, guides, and resources for deploying and operating with [Kamal](https://kamal-deploy.org/).

**Website:** [awesomekamal.com](https://awesomekamal.com/) · **Suggest a resource:** [GitHub issues](https://github.com/awesome-kamal/awesome-kamal/issues/new/choose)

> Independent community project, supported by [Upstate](https://upstate.run/). Not affiliated with the official Kamal maintainers.

## Official

- [Kamal](https://github.com/basecamp/kamal) — Official deployment tool for containerized applications.
- [kamal-proxy](https://github.com/basecamp/kamal-proxy) — HTTP proxy used by modern Kamal deployments.
- [Kamal documentation](https://kamal-deploy.org/) — Official installation, commands, configuration, and upgrades.

## Deployment tools

- [kamal-deploy Action](https://github.com/igor-alexandrov/kamal-deploy) — GitHub Action for automating Kamal deployments.
- [kamal-complete](https://github.com/hschne/kamal-complete) — Shell completion for Kamal commands.
- [Kamal-TUI](https://github.com/stawan15/Kamal-TUI) — Terminal interface for Kamal operations.
- [kamal-panel](https://github.com/wenlingang/kamal-panel) — SSH-oriented interface for managing Kamal deployments.
- [Helmsman](https://github.com/JijoBose/Helmsman) — Local browser interface for Kamal.
- [Shipyrd](https://github.com/Shipyrd/shipyrd) — Team dashboard for Kamal deployment workflows.

## Configuration

- [kamal-lint](https://github.com/davafons/kamal-lint) — Lint and inspect Kamal configuration.
- [kamal-json-schema](https://github.com/RockieStar-Inc/kamal-json-schema) — JSON schema for editor help with Kamal configuration.

## Operations

- [kamal-backup](https://github.com/crmne/kamal-backup) — Scheduled encrypted database and file backups for Rails applications deployed with Kamal.
- [Rails Conductor](https://github.com/nauman/rails-conductor) — Self-hosted control plane for Rails operations, including Kamal and native deployments.
- [DeployAngel](https://github.com/DeployAngel/deployangel-ruby) — Ruby integration for post-deploy verification and telemetry.
- [Automated CrowdSec Kamal](https://github.com/muthuishere/automated-crowdsec-kamal) — Integrate CrowdSec security controls into a Kamal setup.
- [Shoestring](https://github.com/tachyurgy/shoestring) — Self-hosted observability with a Kamal proxy log integration.
- [Upstate](https://upstate.run/) — Production visibility, deployment history, and health checks for Kamal applications. **(commercial)**

## Infrastructure

- [kamal-ansible-manager](https://github.com/guillaumebriday/kamal-ansible-manager) — Provision and manage servers with Ansible for Kamal.
- [terraform-hetzner](https://github.com/luizkowalski/terraform-hetzner) — Terraform provisioning examples for Hetzner deployments.
- [kitsune-kit](https://github.com/OmarHrra/kitsune-kit) — VPS bootstrap and server provisioning toolkit.
- [dsd-vps-kamal](https://github.com/janraasch/dsd-vps-kamal) — VPS deployment tooling for Django with Kamal.
- [shipyard](https://github.com/onancelabs/shipyard) — Ansible, Caddy, and Kamal infrastructure setup.
- [Single Server](https://github.com/dvassallo/singleserver) — Related single-server hosting approach incorporating Kamal.

## Examples & recipes

- [kamalduo](https://github.com/scarver2/kamalduo) — Small Sinatra application deployed with Kamal 2.
- [Kamal frontend/backend demo](https://github.com/hboon/kamal-frontend-backend-demo) — Frontend, backend, and database deployment example.
- [GhostCMS on Kamal and Hetzner](https://github.com/h4nz0x/GhostCMS-Kamal-Hetzner) — Deploy Ghost CMS using Kamal on Hetzner.
- [kamal-quake](https://github.com/neonwatty/kamal-quake) — Deploy the QuakeJS game with Kamal.
- [grimmory-kamal](https://github.com/eval/grimmory-kamal) — Kamal deployment of a self-hosted library application.
- [Embeddings inference accessory](https://github.com/marianposaceanu/mp-com-embeddings) — Run embedding inference alongside an application.
- [django-emojivote](https://github.com/janraasch/django-emojivote) — Django demo showing Kamal deployment patterns.

## Learning

- [Kamal Handbook](https://kamalmanual.com/handbook/) — Long-form guide to deploying and operating with Kamal. **(commercial)**
- [Kamal Wiki](https://kamal.wiki/) — Unofficial Kamal tutorials; check articles for version compatibility.
